# React + Vite + Electron

## Desktop app

- Install dependencies with `npm install`.
- Run the desktop app with hot reload using `npm run desktop:dev`.
- Build the frontend and launch the desktop app using `npm run desktop`.

The desktop app can open a raw-data folder in the operating system's file
manager when the backend is running on the same computer and the returned path
exists there. The regular browser version cannot launch the operating system's
file manager.

## Web development

Run `npm run dev` to start the Vite development server in a browser.

Run `npm run lint` and `npm run build` to lint and build the frontend.
